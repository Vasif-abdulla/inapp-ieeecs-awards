# InApp - IEEE CS Student Project Awards

**Inspiring New Solutions, Propelling Innovation, Realizing Excellence**

The **InApp - IEEE CS Student Project Awards** is a prestigious competition designed to celebrate and recognize outstanding student achievements in software development. Organized in partnership with the IEEE Computer Society Kerala Chapter, this platform empowers the next generation of technocrats to showcase their creativity, technical rigor, and real-world problem-solving skills.

![Project Banner](/heading.png)

## 🚀 Features

- **Modern & Responsive Design**: A fully responsive interface optimized for desktop, tablet, and mobile devices.
- **Interactive Timeline**: Visual roadmap of important dates and deadlines (`Coming Soon`).
- **Dynamic Stats Section**: CSS Grid-powered statistics display, ensuring consistency across all screen sizes.
- **Awards & Guidelines**: Clear, structured information about eligibility, evaluation criteria, and prizes.
- **Mobile-First Navigation**: polished mobile sidebar with smooth transitions, dark mode toggle support, and intuitive layout.
- **Standardized Iconography**: Consistent visual language using Lucide React icons.

## 🛠️ Tech Stack

- **Framework**: [Next.js 14](https://nextjs.org/) (App Router)
- **Language**: [TypeScript](https://www.typescriptlang.org/)
- **Styling**: CSS Modules, Vanilla CSS
- **Icons**: [Lucide React](https://lucide.dev/)
- **Deployment**: Vercel (Recommended)

## 📦 Getting Started

Follow these steps to set up the project locally.

### Prerequisites

- Node.js 18.17 or later
- npm, yarn, pnpm, or bun

### Installation

1. **Clone the repository:**
   ```bash
   git clone https://github.com/your-username/inapp-ieeecs-awards.git
   cd inapp-ieeecs-awards
   ```

2. **Install dependencies:**
   ```bash
   npm install
   # or
   yarn install
   # or
   pnpm install
   ```

3. **Run the development server:**
   ```bash
   npm run dev
   ```

4. **Open your browser:**
   Navigate to [http://localhost:3000](http://localhost:3000) to view the application.
